# Nexora AI
# Personal AI Creator, Study, Research, Project & Career Assistant

This is a modular personal AI platform built with FastAPI and React.

## Services
- Backend: FastAPI (Python)
- Frontend: React (Vite, TypeScript, Tailwind CSS)
- Database: PostgreSQL with pgvector
- Cache / Queue: Redis
